# Инструкция по подготовке и запуску проекта на Windows Git Bash

## 📋 Требования

- **Windows 10/11** с установленным **Git Bash**
- **Python 3.8 или выше** (скачать с https://www.python.org/downloads/)
- Доступ в интернет (для загрузки зависимостей)

## 🚀 Пошаговая инструкция

### Шаг 1: Открытие Git Bash

1. Откройте проводник Windows
2. Перейдите в папку проекта: `maritime_colreg_system`
3. Кликните правой кнопкой мыши в пустом месте папки
4. Выберите **"Git Bash Here"**

Или откройте Git Bash и перейдите в папку проекта:
```bash
cd /c/path/to/maritime_colreg_system
```

### Шаг 2: Создание виртуального окружения

Виртуальное окружение изолирует зависимости проекта от системных библиотек Python.

```bash
python -m venv venv
```

### Шаг 3: Активация виртуального окружения

```bash
source venv/Scripts/activate
```

После активации вы увидите `(venv)` в начале строки команд:
```bash
(venv) user@hostname MINGW64 /c/path/to/maritime_colreg_system
```

### Шаг 4: Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Шаг 5: Запуск симуляции

```bash
python test_system.py
```

Вы увидите сообщение об успешном запуске:
```
============================================================
🚢 МППСС-72: Система Расхождения Судов
============================================================

Запуск симуляции...

✅ Сервер запущен!

📍 Откройте в браузере: http://localhost:8080
```

### Шаг 6: Открытие веб-интерфейса

1. Откройте любой браузер (Chrome, Firefox, Edge)
2. Введите в адресной строке: **http://localhost:8080**
3. Нажмите кнопку **"▶ Запуск"** для начала симуляции

### Шаг 7: Остановка симуляции

Для остановки нажмите в терминале **Ctrl+C**

## 🔧 Решение проблем

### Ошибка: "python: command not found"

Убедитесь, что Python установлен и добавлен в PATH:
```bash
which python
```

Если не найдено, попробуйте:
```bash
py -m venv venv
source venv/Scripts/activate
```

### Ошибка: "Address already in use"

Порт 8080 занят другой программой. Используйте другой порт:
```bash
export PORT=8081
python test_system.py
```

Затем откройте: http://localhost:8081

### Ошибка при установке зависимостей

Попробуйте установить каждую зависимость отдельно:
```bash
pip install numpy
```

### Браузер не открывает страницу

1. Проверьте, что сервер запущен (смотрите логи в терминале)
2. Проверьте URL: http://localhost:8080 (без пробелов)
3. Попробуйте другой браузер

## 🎮 Использование

После запуска:

1. **Наблюдайте за картой** - ваше судно в центре, другие суда вокруг
2. **Следите за индикаторами риска**:
   - 🔴 Красный - высокий риск столкновения
   - 🟠 Оранжевый - средний риск
   - 🟢 Зеленый - низкий риск/безопасно
3. **Читайте решения** - система показывает маневры по МППСС-72
4. **Смотрите сигналы** - звуковые и световые сигналы (• •• •••)

## 🔄 Повторный запуск

Для повторного запуска достаточно:

```bash
cd /c/path/to/maritime_colreg_system
source venv/Scripts/activate
python test_system.py
```

## 📞 Поддержка

При возникновении проблем:
1. Проверьте версию Python: `python --version`
2. Проверьте список установленных пакетов: `pip list`
3. Пересоздайте виртуальное окружение при необходимости
