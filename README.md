В этом репозитории будет реализован модуль для внедрения в БЭК, который поможет ему расходиться с другими судами по правилам МППСС-72.

Основные виды судов, с которыми будет знаком наш модуль: nuc, ram, cbd, fishing, sail, mech.


Основные правила, которые будут учтены в модуле (кратко из основного объёма правил COLREG_72_Structured.md):

 1. Правило 3: Определения
  Здесь даются юридические определения каждого статуса:
   * NUC (Not Under Command) — Судно, лишенное возможности управляться.
   * RAM (Restricted in Ability to Maneuver) — Судно, ограниченное в возможности маневрировать (из-за характера работ).
   * CBD (Constrained By Draught) — Судно, стесненное своей осадкой.
   * FISHING — Судно, занятое ловом рыбы.
   * SAIL — Парусное судно.
   * MECH (Power-driven vessel) — Судно на ходу, приводимое в движение механизмом.

  2. Правило 18: Обязанности между судами (ГЛАВНОЕ)
  Это правило устанавливает "иерархию уступчивости". Если суда находятся на виду друг у друга (кроме ситуаций обгона,
  узкостей и СРД), приоритет распределяется так (сверху вниз):

   1. NUC (Высший приоритет — все уступают ему)
   2. RAM (Уступает только NUC)
   3. CBD (Должно следовать с особой осторожностью, остальные стараются не затруднять его движение)
   4. FISHING (Уступает NUC и RAM)
   5. SAIL (Уступает NUC, RAM и FISHING)
   6. MECH (Низший приоритет — уступает всем вышеперечисленным)

  3. Правило 9: Узкости
  Здесь иерархия меняется:
   * Суда SAIL и суда длиной менее 20 метров не должны затруднять движение судов (MECH), которые могут безопасно
     следовать только в пределах фарватера.
   * Суда FISHING не должны затруднять движение любых других судов, следующих в пределах фарватера.

  4. Правила 21–30: Огни и знаки
  Эти правила описывают, как визуально отличить эти суда (то, что ваш модуль cv-core уже должен уметь распознавать):
   * NUC: два красных огня (ночью) / два шара (днем).
   * RAM: Красный-Белый-Красный огни / Шар-Ромб-Шар.
   * CBD: три красных огня / цилиндр.
   * FISHING: Красный над Белым (сети) или Зеленый над Белым (трал) / два конуса вершинами вместе.
   * SAIL: Красный над Зеленым на мачте.

  5. Правило 35: Звуковые сигналы при ограниченной видимости
   * NUC, RAM, CBD, FISHING, SAIL подают одинаковый сигнал: один продолжительный и два коротких (— • •) каждые 2 минуты.
   * MECH подает один продолжительный (—) или два продолжительных (— —) сигнала.


   Основные логика:
   в первую очередь модуль должен проверять поле status у цели. Если оно отличается от normal/mech, вы должны
  применять логику Правила 18, игнорируя базовые правила пересечения курсов (Правило 15). Например, даже если NUC
  находится у вас слева, вы обязаны ему уступить, хотя обычно уступает тот, кто слева.\
