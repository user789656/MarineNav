# COLREG Decision System

Система принятия решений для расхождения судов по правилам МППСС-72 (COLREGs-72).

## Структура проекта

```
colreg-decision-system/
├── core/                   # Ядро системы принятия решений
│   ├── __init__.py
│   ├── vessel.py          # Классы судов и их состояния
│   ├── collision.py       # Расчет TCPA/DCPA и определение опасности
│   └── decision.py        # Логика принятия решений по МППСС-72
├── models/                # Модели данных и ML интеграция
│   ├── __init__.py
│   └── cv_integration.py  # Интеграция с cv-core для распознавания типов судов
├── utils/                 # Утилиты
│   ├── __init__.py
│   └── signals.py         # Звуковые и световые сигналы
├── frontend/              # Web-визуализация
│   ├── static/
│   │   ├── css/
│   │   │   └── style.css
│   │   └── js/
│   │       └── map.js
│   └── templates/
│       └── index.html
├── main.py                # Точка входа приложения
├── test_system.py         # Тестовый скрипт
├── requirements.txt       # Зависимости
└── README.md             # Документация
```

## Установка на Windows (Git Bash)

### Требования
- Python 3.8 или выше
- Git Bash (для Windows)
- Доступ в интернет для установки зависимостей

### Пошаговая инструкция

#### Шаг 1: Открытие Git Bash и переход в директорию проекта

```bash
# Откройте Git Bash
# Перейдите в директорию проекта
cd /workspace/colreg-decision-system
```

#### Шаг 2: Создание виртуального окружения

```bash
# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения (Windows Git Bash)
source venv/Scripts/activate
```

После активации вы увидите `(venv)` в начале строки команд.

#### Шаг 3: Установка зависимостей

```bash
# Обновление pip
python -m pip install --upgrade pip

# Установка всех зависимостей
pip install -r requirements.txt
```

> **Примечание:** Установка может занять несколько минут. Если возникают ошибки при установке torch или ultralytics, убедитесь что у вас установлена последняя версия Python.

#### Шаг 4: Запуск тестового скрипта (опционально)

```bash
# Проверка работы системы
python test_system.py
```

Вы должны увидеть результаты тестирования расчета TCPA/DCPA и классификации ситуаций.

#### Шаг 5: Запуск веб-приложения

```bash
# Запуск сервера
python main.py
```

Или альтернативно:

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

#### Шаг 6: Открытие веб-интерфейса

Откройте браузер и перейдите по адресу:
```
http://localhost:8000
```

## Возможности

- **Расчет TCPA/DCPA**: Определение времени и дистанции до точки максимального сближения
- **Классификация судов**: Интеграция с CV-модулем для определения типа судна
- **Принятие решений**: Автоматическое определение маневра по правилам МППСС-72
- **Сигналы**: Отображение звуковых и световых сигналов при маневрировании
- **Web-визуализация**: Интерактивная карта с отображением судов и их траекторий

## API Endpoints

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/` | GET | Главная страница с веб-интерфейсом |
| `/api/analyze` | POST | Анализ ситуации и получение рекомендаций |
| `/api/scenario/{type}` | GET | Получение预设 сценария (head_on, crossing, overtaking) |
| `/api/signals` | GET | Информация о всех сигналах МППСС-72 |

## Правила МППСС-72

Система реализует следующие правила:
- **Правило 13**: Обгон
- **Правило 14**: Ситуация сближения судов, идущих прямо друг на друга
- **Правило 15**: Ситуация пересечения курсов
- **Правило 16**: Действия судна, уступающего дорогу
- **Правило 17**: Действие судна, которому уступают дорогу
- **Правило 18**: Взаимные обязанности судов
- **Правило 19**: Плавание судов при ограниченной видимости
- **Правило 34**: Сигналы маневроуказания и предупреждения

## Интеграция с cv-core

Для работы с распознаванием типов судов через камеру:

1. Убедитесь что cv-core-main находится в родительской директории
2. Модели должны быть расположены в `cv-core-main/models/`
3. При отсутствии моделей система работает в режиме симуляции
